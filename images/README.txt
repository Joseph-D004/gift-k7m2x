========================================================================
PHOTOS FOLDER: INSTRUCTIONS FOR PRECIOUS'S BIRTHDAY PAGE
========================================================================

Drop your photos directly into this "images" folder and rename them to match
these exact filenames:

1. opening.jpg
   - This is the full-screen photo on the very first screen.
   - Recommended: A nice portrait or full-body photo of Precious with good lighting.
   - Vertical (portrait orientation) looks best on mobile phones.

2. story1.jpg
   - Memory 1: Represents the beginning / 100 level / early campus days.

3. story2.jpg
   - Memory 2: Represents meaningful moments, long talks, or shared memories.

4. story3.jpg
   - Memory 3: Represents growing closer and being there for each other.

5. gallery1.jpg
   - First photo in the appreciation gallery (square or portrait).

6. gallery2.jpg
   - Second photo in the appreciation gallery (square or portrait).

7. gallery3.jpg
   - Third photo in the appreciation gallery (square or portrait).

------------------------------------------------------------------------
TIPS:
- If your photos are .png or .jpeg, you can either rename the file extension
  to .jpg, or open index.html and adjust the extension (e.g., gallery1.png).
- If an image file hasn't been added yet, the page automatically displays
  a soft, elegant placeholder showing which image belongs there.
